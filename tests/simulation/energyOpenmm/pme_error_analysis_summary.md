# PME Error Analysis Summary

## 中等复杂度系统分析总结 (Medium Complexity System Analysis)

### 系统参数
- 20个原子 (12个离子 + 8个配体原子)
- 3.5 nm 立方盒子
- 1.2 nm 截断距离
- 总电荷：0 (中性系统)

### 主要发现

#### 1. **远距离的PME倒空间计算存在问题**
倒空间（reciprocal space）贡献异常大，占总能量的283.8%：
- 实空间（real space）: 0.0206 kJ/mol (0.0%)
- 倒空间（reciprocal）: 2503.3757 kJ/mol (283.8%)
- 自能量（self）: -3385.4886 kJ/mol (383.8%)
- 总能量：-882.0923 kJ/mol

这表明倒空间计算确实有问题，因为正常情况下各部分应该相互平衡。

#### 2. **近距离计算基本正确**
直接截断计算显示近距离相互作用为 -116.0184 kJ/mol，这部分计算是合理的。

#### 3. **与OpenMM的差异**
- PyGCMC: -882.0923 kJ/mol
- OpenMM: -922.0880 kJ/mol
- 差异: 39.9958 kJ/mol (4.34%)

#### 4. **距离分布分析**
```
距离范围        对数    能量贡献     占比
0.0-0.5 nm     28对    -117.73    14.0%
0.5-1.0 nm     32对      1.71    -0.2%
1.0-1.2 nm     22对      0.00     0.0%
1.2-2.0 nm     92对   -1296.73   154.2%
2.0+ nm        16对     572.03   -68.0%
```

大部分能量贡献来自1.2-2.0 nm范围，这超出了截断距离，需要PME来正确处理。

### 误差原因分析

1. **倒空间振幅过大**：倒空间贡献（2503 kJ/mol）远大于合理值，表明FFT或网格电荷分配可能有问题。

2. **实空间贡献过小**：实空间仅贡献0.02 kJ/mol，而直接计算显示近距离应有约-116 kJ/mol的贡献。

3. **可能的原因**：
   - B样条插值实现可能有误
   - 网格电荷分配（charge spreading）算法问题
   - FFT归一化因子不正确
   - 倒空间求和的收敛参数设置不当

### 建议的修复步骤

1. **检查charge spreading实现**：确保电荷正确分配到网格点
2. **验证B样条计算**：检查B样条权重是否正确
3. **检查FFT归一化**：确保FFT正反变换的归一化因子正确
4. **验证倒空间格林函数**：检查倒空间的势能计算是否正确

### 结论

问题确实出在远距离的PME倒空间计算上。倒空间贡献异常大（283.8%），而实空间贡献几乎为零，这不符合PME的正常行为。需要仔细检查倒空间计算的实现，特别是电荷网格分配和FFT相关的代码。
