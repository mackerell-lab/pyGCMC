## 作图数据（Log-Log曲线）

```python
# Python plotting code
import matplotlib.pyplot as plt
import numpy as np

# Data
N = np.array([8, 27, 64, 125])
TIP3P = np.array([389805, 21136, 3722, 1041])
SWM4 = np.array([7426, 799, 84, 13])

# Create log-log plot
plt.figure(figsize=(6, 5))
plt.loglog(N, TIP3P, 'o-', label='TIP3P', markersize=10, linewidth=2)
plt.loglog(N, SWM4, 's-', label='SWM4-NDP', markersize=10, linewidth=2)

# Add power law fits
p_tip3p = np.polyfit(np.log(N), np.log(TIP3P), 1)
p_swm4 = np.polyfit(np.log(N), np.log(SWM4), 1)

# Plot fit lines
N_fit = np.logspace(0.9, 2.1, 100)
plt.loglog(N_fit, np.exp(p_tip3p[1]) * N_fit**p_tip3p[0], 
           '--', color='blue', alpha=0.5, 
           label=f'TIP3P: N^{p_tip3p[0]:.1f}')
plt.loglog(N_fit, np.exp(p_swm4[1]) * N_fit**p_swm4[0], 
           '--', color='orange', alpha=0.5,
           label=f'SWM4: N^{p_swm4[0]:.1f}')

plt.xlabel('水分子数 (N)', fontsize=12)
plt.ylabel('GCMC步数/秒', fontsize=12)
plt.title('GCMC性能缩放', fontsize=14)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
```

## 关键信息总结

### 性能差异
- **平均速度比**: 50倍 (TIP3P快于SWM4)
- **速度比范围**: 26-77倍，随系统增大而增加

### 缩放行为
- **TIP3P**: O(N^2.2) - 略差于理想的O(N²)
- **SWM4**: O(N^2.3) - 额外的SCF开销

### 实际应用时间
对于64个水分子系统，100万GCMC步需要：
- **TIP3P**: 4.5分钟
- **SWM4**: 3.3小时

### 模型选择建议
1. **小系统 (<100水)**: 两者皆可，SWM4提供更高精度
2. **中等系统 (100-500水)**: 优先选择TIP3P
3. **大系统 (>500水)**: 仅使用TIP3P或考虑GPU加速

### 技术细节
- **测试环境**: 单核CPU，C++实现
- **截止距离**: 1.2 nm
- **SCF参数**: tolerance=10 kJ/mol/nm, maxIter=50
- **Thole筛选**: 简化处理以提高速度

## 结论
对于GCMC模拟，由于需要大量能量计算，加性模型（TIP3P）在计算效率上具有显著优势。极化模型（SWM4-NDP）虽然提供更高精度，但计算成本高出50倍，仅适用于小系统或对精度要求极高的应用。
